# drop-number-game
Drop number game with multi linked list 
In this project, I implemented the Drop Number Game in Java by using a multi-linked list structure. The game is played on a 7x5 grid. Numbers are dropped from the top into a selected column. If two same numbers meet, they merge and form a new number with double value.
The main purpose of the project is to use linked list logic instead of arrays. Empty cells are not stored. Only filled cells are kept as nodes.
